# Handla

Handla är en enkel inköpslista för Android utvecklad med Kotlin och Jetpack Compose.

## Funktioner

- Lägga till varor och välja kategori
- Markera varor som köpta
- Redigera och ta bort varor
- Visa antal köpta varor

## Teknik

Kotlin, Jetpack Compose, Material 3, ViewModel

## Problem och lösning

Under utvecklingen hade jag problem med placeringen av komponenterna på skärmen. Jag löste problemet genom att använda Scaffold och Column

## Verktyg och lärande

Under utvecklingen använde jag kursmaterial, Android Studio och ChatGPT.

ChatGPT hjälpte mig att förstå koden och felsöka problem. Det mest lärorika var att förstå hur ViewModel, UiState och gränssnittet samverkar.
